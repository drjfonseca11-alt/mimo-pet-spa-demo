# Mimo Pet Spa — demo de peluquería canina

Página demostrativa para una peluquería y spa de mascotas. Incluye servicios, galería, testimonios de muestra y un formulario que prepara la solicitud de cita en WhatsApp.

## Ver la página

Abre `index.html` en el navegador. El diseño es estático y no requiere instalación.

## Antes de usarla con un negocio

- Reemplaza el número de WhatsApp de ejemplo en `app.js` y los enlaces.
- Confirma precios, servicios, dirección y horario.
- Cambia los testimonios de muestra por experiencias reales autorizadas.
- Las fotografías y las fuentes se cargan desde internet.
